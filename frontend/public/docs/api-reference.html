JWT Bearer Authentication

All protected endpoints require a signed JWT in the Authorization: Bearer <token> header. Tokens expire in 60 minutes. Obtain one via POST /api/auth/login or POST /api/auth/verify-otp. Refresh via POST /api/auth/refresh.

Role-Based Access Control
👑
Admin
role_id: 1
Platform super-user. Full system access. Provisions HR/Recruiter accounts, manages users, and views all audit logs.
🧑‍💼
HR
role_id: 2
Creates and owns job requisitions. Approves candidates, schedules interviews, reviews HM decisions, and manages offers.
🔍
Recruiter
role_id: 3
Sources and screens candidates. Claims candidates, runs matching engine, manages tasks, and creates draft offers.
🙋
Candidate
role_id: 4
Self-registers and maintains profile. Uploads resume, views pipeline, selects interview slots, and responds to offers.
